## EdgeMark v1.0.0

First public release.

* Edge tabs for **bookmarks** (folders, programs, shortcuts, any files) and **notes** (plain .txt files)
* Groups with colors, collapsing and drag & drop; ready-made "Quick access" group
* Tray icons, global hotkeys (Ctrl+Alt+` / Ctrl+`) and optional Steam-like overlay mode
* Tabs hide in full-screen games and in programs you choose
* Windows 11 look, light/dark theme, custom colors, opacity and 50–200% scale
* English and Russian interface

**Download:** `EdgeMark.exe` below — a single self-contained file, no installation and no .NET needed. Windows 10/11 x64.
If SmartScreen warns about an unknown publisher: More info → Run anyway.
